## Tableau de bord

Le tableau de bord est la page d'accueil de Rocket Auth. Il se rafraîchit automatiquement toutes les minutes.

| Bloc | Contenu |
|---|---|
| **En-tête** | État global de la plateforme (opérationnelle, dégradée ou en incident), heure de la dernière mise à jour |
| **Actions rapides** | Pour les administrateurs : nouveau client OAuth, nouvelle application, nouvel utilisateur. Pour les autres : applications autorisées. |
| **Indicateurs** | Connexions aux applications sur 30 jours (avec l'évolution par rapport aux 30 jours précédents), connexions à Rocket Auth, sessions applicatives actives (jetons de rafraîchissement valides, par utilisateur et par application) et, pour les administrateurs, clients OAuth (actifs, de confiance) et utilisateurs (locaux, LDAP, SSO) |
| **Dernières connexions aux applications** | Les 6 dernières connexions : à Rocket Auth, autorisations accordées et refusées |
| **Intégrations** | Administrateurs : les applications externes (jetons `raa_…`) |
| **Activité (30 derniers jours)** | Une barre par jour : autorisations, connexions et refus |
| **Activité récente** | Connexions aux applications, autorisations refusées, nouveaux clients OAuth, nouveaux utilisateurs et nouvelles applications, groupés par jour |
| **État des services** | Administrateurs uniquement, voir ci-dessous |
| **Services & raccourcis** | Documentation, changelog, API et, pour les administrateurs, le document de découverte OpenID Connect |

Un utilisateur qui n'est pas administrateur voit le même tableau de bord, limité à **ses** connexions et aux applications qu'il a autorisées, sans l'état des services.

### État des services

| Service | Opérationnel | Dégradé | Hors service |
|---|---|---|---|
| **Base de données** | Répond (version affichée) | | Injoignable |
| **Tâches de fond** | Aucune tâche en retard | Des tâches attendent depuis plus de 5 minutes : vérifiez que le worker (`messenger:consume async scheduler_default`) tourne | |
| **Annuaire LDAP** | Le serveur répond : connexion, authentification du compte de service, lecture de la base de recherche | | Serveur injoignable ou authentification refusée |
| **Authentification unique** | Chaque fournisseur OpenID Connect externe actif répond | Une partie des fournisseurs en échec | Tous en échec |
| **Stockage** | Dossier des données accessible en écriture | | Dossier non accessible en écriture |

La base de données, les tâches de fond et le stockage sont vérifiés à l'affichage. L'annuaire et les fournisseurs externes sont contactés en arrière-plan **toutes les 5 minutes** par le worker, ou tout de suite avec **Vérifier maintenant** ; le tableau de bord affiche le dernier résultat, l'erreur éventuelle et depuis quand le service est en échec.

En ligne de commande, `php bin/console app:health:check` lance les vérifications et affiche les résultats (code de sortie 1 si un service est en échec : utilisable par une supervision).

## Ce qui est enregistré

| Événement | Quand |
|---|---|
| Connexion | Un utilisateur se connecte à Rocket Auth (mot de passe, annuaire ou fournisseur externe) |
| Autorisation | Rocket Auth renvoie un utilisateur vers une application avec un code |
| Refus | L'utilisateur refuse la page d'autorisation, ou annule la connexion |

Chaque événement garde l'utilisateur, l'application et l'heure. Le client OAuth garde aussi la date de sa dernière utilisation (**Administration → Clients OAuth**, colonne « Dernier usage »).
