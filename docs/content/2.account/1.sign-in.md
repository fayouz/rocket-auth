## Se connecter à une application

1. Dans l'application (Rocket Print, Rocket Cloud…), cliquez sur **Se connecter avec Rocket Auth**. En mode suite, l'application vous envoie directement vers Rocket Auth.
2. Si vous n'êtes pas encore connecté à Rocket Auth, sa page de connexion s'affiche : votre compte local, ou votre mot de passe d'annuaire pour un compte LDAP.
3. Rocket Auth vous renvoie vers l'application, connecté. Les fois suivantes, tant que votre session Rocket Auth est ouverte, vous n'avez rien à saisir.

## La page d'autorisation

La première fois qu'une application vous connecte, Rocket Auth vous demande votre accord :

- le nom et la description de l'application, et le compte avec lequel vous êtes connecté (**Ce n'est pas vous ?** pour changer de compte) ;
- ce que l'application pourra faire :

| Scope | Ce que l'application reçoit |
|---|---|
| `openid` | Vous identifier (identifiant unique de votre compte) |
| `profile` | Connaître votre nom et prénom |
| `email` | Connaître votre adresse email |
| `groups` | Connaître vos groupes |
| `offline_access` | Rester connecté en votre absence |

- l'adresse vers laquelle vous serez renvoyé.

**Autoriser** vous renvoie vers l'application, connecté ; **Refuser** vous y renvoie sans connexion. Votre accord est retenu : Rocket Auth ne vous le redemande que si l'application demande davantage.

::note
Les applications **de confiance**, comme les briques de la suite Rocket, ne demandent pas d'accord : elles sont déclarées par vos administrateurs.
::

Si la demande est invalide (application inconnue ou désactivée, adresse de retour non déclarée), Rocket Auth affiche **Connexion impossible** au lieu de vous renvoyer vers l'application.

## Applications autorisées

Le menu **Mon compte → Applications autorisées** liste les applications que vous avez autorisées : ce qu'elles peuvent faire, la date de votre accord et votre dernière connexion.

**Retirer l'accès** vous déconnecte de l'application : ses jetons de rafraîchissement sont révoqués, et elle vous redemandera votre accord à la prochaine connexion. Les applications de confiance n'apparaissent pas dans cette liste.

## Se déconnecter

Quand vous vous déconnectez d'une application branchée sur Rocket Auth, elle vous envoie sur la page de déconnexion de Rocket Auth : votre session Rocket Auth se termine, puis vous revenez sur l'application si elle a déclaré cette adresse. Sinon, Rocket Auth affiche **Vous êtes déconnecté**.

Les autres applications gardent leur propre session. Une nouvelle connexion par Rocket Auth vous demandera de vous identifier à nouveau.
